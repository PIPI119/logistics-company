# Northway Logistics — five-page company site (demo)

Static site: home, services, tariffs (with an offline delivery price calculator),
documents and a contact form. Shared `style.css` and `script.js`, no dependencies.

The company, phone numbers and addresses are invented for the demo. The request form
opens a prefilled Telegram share message instead of sending anything to a server.

## Run locally

Open `index.html` in any browser — no build step required.
